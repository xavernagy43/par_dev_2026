# par_dev_2026
Parallel development Repo


Beadandó témája:

C#-ban készült Mandelbrot-halmazon alapuló képgenerálás a választott feladatom. A program lényege, hogy a képpontokhoz kiszámolja, melyek tartoznak a halmazhoz, majd az eredmények alapján elkészíti a képet. A mérési eredmények (hamarosan) a futási időt fogják reprezentálni a következő szempontok alapján:
    - workerGroup-ok nagységa szerint
    - iteráció mennyisége szerint
    - kép felbontása szerint

A méréseket majd egy pdf-be fogom tenni, a beadandó fő mappába. (Terv szerint tartalmazni fog oszlop és vonaldiagrammot is a vizuális ábrázoláshoz.)
